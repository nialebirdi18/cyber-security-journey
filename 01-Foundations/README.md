# Foundations

This folder contains foundational topics and resources to learn core skills used across cybersecurity.

## Networking

Add notes, diagrams, and exercises for TCP/IP, OSI model, subnetting, routing, switching, and network troubleshooting.

## Linux

Add notes for Linux basics, shell usage, permissions, package management, and common security tools.

## SQL

Add SQL fundamentals, queries, database security, injection prevention, and sample exercises.

## Windows

Add Windows fundamentals, administration basics, and security-relevant topics.

## PowerShell

Add PowerShell scripting, automation, and security-focused scripts.
