# Exams & Certification Path

This folder collects recommended exams, a suggested order to take them, and checklists to track study progress and practical lab work.

## Suggested certification path (entry → advanced)

1. Entry / Foundations
   - CompTIA Network+ — core networking fundamentals (subnetting, TCP/IP, routing, switching).
   - Google Cybersecurity Certificate — structured introduction to cybersecurity concepts and practical labs.
   - (Optional) CompTIA IT Fundamentals or Google IT Support for absolute beginners.

2. Core security certifications
   - CompTIA Security+ — baseline security knowledge (access control, cryptography, threats/mitigation).
   - Vendor-neutral certs like (optional) CEH / eLearnSecurity Junior levels for basic offensive awareness.

3. Hands-on practice & HTB
   - Hack The Box (HTB) practice (easy → medium → hard boxes)
   - HTB certifications: aim for HTB CPTS and HTB SL1 (hands-on proof of practical skill)

4. Cloud & specialization
   - AWS Certified Cloud Practitioner or Microsoft Azure Fundamentals (cloud basics)
   - AWS Solutions Architect Associate / Azure Administrator (deeper cloud networking & services)
   - Cloud security certs (optional): AWS Security Specialty, Azure Security Engineer

5. Advanced / professional
   - Offensive: OSCP (Offensive Security Certified Professional) or equivalent hands-on pentesting certs
   - Defensive: Splunk/Elastic/Sentinel specialist certs, Certified Threat Intelligence Analyst, or advanced cloud security certs

## How to use this folder

- Each exam should have its own subfolder containing:
  - study-plan.md (topics, timeline)
  - resources.md (official guides, recommended courses, practice tests)
  - labs/ (VM images, scripts, PCAPs)
  - checklist.md (ready-for-exam checklist)

Example structure after adding an exam (CompTIA Network+):
```
11-Exams/
  NetworkPlus/
    study-plan.md
    resources.md
    labs/
    checklist.md
```

## Quick list of recommended exams & why

- CompTIA Network+ — essential for networking foundations used across security roles.
- Google Cybersecurity Certificate — good structured entry course that includes practical labs.
- CompTIA Security+ — baseline security certification widely recognized by employers.
- HTB CPTS / SL1 — hands-on practical certification to demonstrate real-world offensive skills.
- AWS/Azure Fundamentals and Associate-level certs — understand cloud data flows and services.
- OSCP / professional pentest or cloud security certs — for advanced hands-on or specialized roles.
